## 🚀 Installation Guide

Choose the method tailored for your development setup:

### 1. Visual Studio Code
- **Via Marketplace UI**:
  1. Press `Ctrl + Shift + X` (or `Cmd + Shift + X` on macOS) to open the **Extensions** view.
  2. Search for **`zevora`**.
  3. Click **Install** on the extension by publisher `zevora`.
- **Via Terminal**:
  ```bash
  code --install-extension zevora.zevora
  ```

---

### 2. Cursor
- **Via Cursor Extensions**:
  1. Press `Ctrl + Shift + X` (or `Cmd + Shift + X` on macOS).
  2. In the search bar, type **`zevora`**.
  3. Click **Install**.
- **Via Terminal**:
  ```bash
  cursor --install-extension zevora.zevora
  ```

---

### 3. Google Antigravity
- **Via Antigravity Extensions**:
  1. Open the **Extensions** panel (`Ctrl + Shift + X` / `Cmd + Shift + X`).
  2. Search for **`zevora`** (fetched seamlessly via Open VSX Registry).
  3. Click **Install** to activate immediately.
- **Via Command Palette**:
  Press `Ctrl + Shift + P` → run `Extensions: Install Extension` → search **`zevora`**.

---

### 4. Windsurf & VSCodium
- **Via Open VSX In-App Search**:
  1. Open the Extensions sidebar (`Ctrl + Shift + X` / `Cmd + Shift + X`).
  2. Search for **`zevora`**.
  3. Click **Install**.
- **Via CLI**:
  ```bash
  # VSCodium
  codium --install-extension zevora.zevora

  # Windsurf
  windsurf --install-extension zevora.zevora
  ```

---

### 5. Manual / Offline VSIX Install (All Editors)
If you are behind a corporate firewall, proxy, or working offline:
1. Download the latest `zevora-0.0.2.vsix` from [GitHub Releases](https://github.com/wahidulsami/Zevora/releases).
2. Open your code editor and press `Ctrl + Shift + X` (or `Cmd + Shift + X`).
3. Click the **`···`** (Views and More Actions) menu in the top-right corner of the Extensions panel.
4. Select **Install from VSIX...** and select the downloaded `.vsix` file.
5. If prompted, reload your editor window (`Developer: Reload Window`).

---

### 6. Install from Source (For Contributors)
```bash
# 1. Clone the repository
git clone https://github.com/wahidulsami/Zevora.git
cd Zevora/zevora-vscode

# 2. Open in your editor
code . # or cursor . / codium .

# 3. Press F5 to launch an Extension Development Host with Zevora preloaded!
```

## ⚡ Built-in Quick Theme Switcher

Never scroll through hundreds of installed themes again. Zevora includes a dedicated quick switcher command:

1. Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on macOS).
2. Type and select **`Zevora: Switch Theme`**.
3. Choose your flavor from the quick-pick dropdown.

```
> Zevora: Switch Theme
  🌙 Zevora Dark (Signature neon purple)
  🌌 Zevora Midnight (Deep navy & electric cyan)
  🍃 Zevora Emerald (Forest night & radiant mint)
  🌋 Zevora Ember (Warm charcoal & glowing amber)
  🌑 Zevora Eclipse (Obsidian black & fiery orange)
```

> 💡 **Zero Runtime Overhead**: The extension only activates when the switcher command is triggered. Zero telemetry, zero lingering background daemons, zero performance penalty.

## ❓ Troubleshooting & FAQ

<details>
<summary><b>Q: I installed Zevora but the theme colors didn't apply automatically.</b></summary>
<br/>
Press <code>Ctrl + K, Ctrl + T</code> (or <code>Cmd + K, Cmd + T</code> on macOS) to open the Color Theme picker, or run <code>Zevora: Switch Theme</code> from the Command Palette (<code>Ctrl + Shift + P</code>). Select any of the 5 Zevora variants.
</details>

<details>
<summary><b>Q: Can I use Zevora in editors that use Open VSX (Cursor, Antigravity, Windsurf, VSCodium)?</b></summary>
<br/>
Yes! Zevora is officially published on Open VSX at <a href="https://open-vsx.org/extension/zevora/zevora">open-vsx.org/extension/zevora/zevora</a>. Searching for <code>zevora</code> in any Open VSX enabled editor will find it immediately.
</details>

<details>
<summary><b>Q: How do I package my own local VSIX build?</b></summary>
<br/>

```bash
cd zevora-vscode
npx @vscode/vsce package
```
This generates `zevora-0.0.2.vsix` ready to install locally or distribute.
</details>
